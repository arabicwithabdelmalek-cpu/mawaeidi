# مواعيدي

تطبيق شخصي عربي لإدارة الحصص الأسبوعية، مع تسجيل دخول وحفظ سحابي عبر Supabase. يدعم التثبيت كتطبيق، الإضافة السريعة من الجدول، النسخ الاحتياطي، المزامنة الفورية، سجل التعديلات، وتنبيهات Web Push.

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى مستودع باسم `mawaeidi`.
2. افتح **Settings → Pages**.
3. اختر **Deploy from a branch**، ثم فرع `main` والمجلد `/ (root)`.
4. بعد ظهور الرابط، أضفه في Supabase ضمن **Authentication → URL Configuration** بوصفه Site URL وRedirect URL.

المفتاح الموجود داخل `index.html` هو مفتاح Supabase قابل للنشر، وتظل البيانات محمية بسياسات Row Level Security. لا تضف أي مفتاح Secret أو Service Role إلى المستودع.

## السجل والتنبيهات

- يسجّل Supabase آخر 50 تغييرًا لكل حساب، مع السماح للحساب نفسه بقراءة سجله فقط.
- تُحفظ اشتراكات التنبيه لكل جهاز خلف سياسات Row Level Security.
- يمكن اختيار 5 أو 10 أو 15 أو 30 أو 60 دقيقة قبل التفعيل، ويُحفظ الاختيار بصورة مستقلة على كل جهاز.
- يحتوي إعداد التنبيهات على اختبار فوري لإشعار الجهاز ورسائل منفصلة لأخطاء الإذن وخدمة المتصفح والحفظ السحابي.
- تستدعي مهمة `pg_cron` دالة `mawaeidi-reminders` كل دقيقة، وتمنع التكرار عبر سجل إرسال فريد.
- توجد مفاتيح VAPID وسر تشغيل المهمة داخل Supabase Vault فقط؛ لا يحتوي المستودع على أي مفتاح خاص.
- ملف `supabase/reminder_cron.sql.example` يوضح إعداد مهمة التشغيل من الأسرار المسماة في Vault.

## ملفات التطبيق

- `manifest.webmanifest`: اسم التطبيق، الألوان، الأيقونات، ووضع الشاشة الكاملة.
- `sw.js`: التخزين الأساسي دون اتصال واستقبال التنبيهات عند إغلاق التطبيق.
- `icons`: أيقونات Android وiPhone.
