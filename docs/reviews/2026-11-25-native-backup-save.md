Native Android backups use ACTION_CREATE_DOCUMENT and bounded 256 KiB chunks, with a unique operation token, ordered offsets, exact expected byte count, and successful stream close before returning saved. No temporary backup file or passphrase is sent to the native bridge. Plain ZIP remains an explicit warned choice; .mwb contains ciphertext only. Cancellation aborts restore. Native document providers may leave partial files after I/O errors or process termination; these are not reported as saved. File picker and memory behavior require physical-device testing. Existing restore remains multi-stage, not atomic. No database change.
