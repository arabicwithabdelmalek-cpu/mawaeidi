# مواعيدي

تطبيق شخصي عربي لإدارة الحصص الأسبوعية والاتفاقات المالية، مع تسجيل دخول وحفظ سحابي عبر Supabase. يدعم التثبيت كتطبيق، الإضافة السريعة من الجدول، النسخ الاحتياطي، المزامنة الفورية، سجل التعديلات، وتنبيهات Web Push.

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى مستودع باسم `mawaeidi`.
2. افتح **Settings → Pages**.
3. اختر **Deploy from a branch**، ثم فرع `main` والمجلد `/ (root)`.
4. بعد ظهور الرابط، أضفه في Supabase ضمن **Authentication → URL Configuration** بوصفه Site URL وRedirect URL.

المفتاح الموجود داخل `index.html` هو مفتاح Supabase قابل للنشر، وتظل البيانات محمية بسياسات Row Level Security. لا تضف أي مفتاح Secret أو Service Role إلى المستودع.

## السجل والتنبيهات

- يسجّل Supabase آخر 50 تغييرًا لكل حساب، مع السماح للحساب نفسه بقراءة سجله فقط.
- تُحفظ اشتراكات التنبيه لكل جهاز خلف سياسات Row Level Security.
- يمكن اختيار تنبيه واحد أو اثنين أو ثلاثة من: 5 أو 10 أو 15 أو 30 أو 60 دقيقة، ويُحفظ الإعداد الافتراضي بصورة مستقلة على كل جهاز.
- يمكن لكل حصة استخدام الإعداد العام، أو مواعيد تنبيه خاصة، أو إيقاف تنبيهها وحدها.
- يحتوي إعداد التنبيهات على اختبار فوري للصوت والاهتزاز ورسائل منفصلة لأخطاء الإذن وخدمة المتصفح والحفظ السحابي.
- تستخدم تنبيهات الويب صوت إشعارات النظام؛ قد يمنعها الوضع الصامت أو «عدم الإزعاج»، ولا تعمل كرنين مستمر مثل تطبيق الساعة.
- تستدعي مهمة `pg_cron` دالة `mawaeidi-reminders` كل دقيقة، وتمنع التكرار عبر سجل إرسال فريد.
- توجد مفاتيح VAPID وسر تشغيل المهمة داخل Supabase Vault فقط؛ لا يحتوي المستودع على أي مفتاح خاص.
- ملف `supabase/reminder_cron.sql.example` يوضح إعداد مهمة التشغيل من الأسرار المسماة في Vault.

## القسم المالي

- يدعم الطالب الخاص والمركز والجهات الأخرى، مع فصل الدخل عن مصروفات التعلّم.
- يدعم الدفع المقدم أو المؤخر، ورصيدًا بعدد حصص، أو حسابًا شهريًا بسعر الحصة.
- يمكن ربط اتفاق واحد بعدة حصص، ومراجعة العدد الفعلي عند الإلغاء أو إضافة حصة استثنائية.
- تُحفظ الدفعات بحسب الرصيد أو الشهر وطريقة الدفع، وتبقى العملات منفصلة في الملخص.
- تشمل النسخة الاحتياطية والسجل والمزامنة البيانات المالية مع المواعيد.

## ملفات التطبيق

- `manifest.webmanifest`: اسم التطبيق، الألوان، الأيقونات، ووضع الشاشة الكاملة.
- `sw.js`: التخزين الأساسي دون اتصال واستقبال التنبيهات عند إغلاق التطبيق.
- `icons`: أيقونات Android وiPhone.
