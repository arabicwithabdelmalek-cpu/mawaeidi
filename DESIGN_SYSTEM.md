# Mawaeidi design system 01 — Petrol / Paper / Brass
This design is experimental on design-development. Preserve wordmark and Kufi artwork.
- Primary #28566B, deep #173A4C; paper #F2F5F5, surface #FFFFFF; muted text #526771.
- Teaching #286B60 on #E7F2ED; learning #855A2E on #F7EFE3; danger #A04749 on #FBEDEE. Always include textual status.
- Cairo interface, Noto Kufi Arabic brand. 12–15px supporting text, 17–22px headings; 44px target where feasible.
- Radius 9 / 13 / 19; 4 / 8 / 12 / 16 / 24 / 32 spacing; subtle shadows, 180ms state changes, reduced-motion support.
- Illustration direction: original custom editorial collage for the hero (820 × 547 WebP, 75,096 bytes, local asset); quiet petrol and brass palette; SVG for empty states. Keep photos limited to meaningful content.
- Design-system.css is the last linked CSS layer, preserving current functions and IDs. Preview build isolates cloud. Do not merge preview build script into production.
