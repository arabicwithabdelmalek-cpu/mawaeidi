# إدارة الطلاب — بيئة التطوير

هذا المجلد هو مساحة اختبار معزولة لتطوير قسم إدارة الطلاب قبل دمجه مع تطبيق «مواعيدي» المنشور.

## النسخة الحالية

تحتوي `student-registry.html` على مرحلة أولى قابلة للتجربة، وتشمل:

- الحقول السبعة عشر نفسها في ورقة Google Sheets المعتمدة.
- بحثًا شاملًا وفلاتر للحالة والمستوى ونوع الدراسة والدولة، مع أكثر من طريقة للترتيب.
- إضافة الطالب وتعديل بياناته وعرض ملفه وحذفه.
- سجل تقدم تعليمي بالتاريخ والمهارة والعنوان والملاحظات والتقييم والخطوة التالية.
- تصدير النتائج المفلترة إلى CSV برؤوس عربية مطابقة للورقة.
- استيراد CSV بعد معاينة عدد الملفات الجديدة والمحدّثة وفحص الأخطاء والتكرارات.
- وضعين واضحين للتجربة:
  - **عرض محلي وهمي:** يعمل فورًا، ولا يرسل أو يحفظ أي بيانات.
  - **قاعدة التطوير:** يتطلب حسابًا في مشروع `Mawaeidi Development`، ويحفظ تحت سياسات RLS.

## قاعدة البيانات التجريبية

- المشروع: `Mawaeidi Development`
- Project ID: `eixeazkkexgfndvfowxa`
- الجداول المستخدمة:
  - `public.mawaeidi_students`
  - `public.mawaeidi_student_progress`
- لا توجد بيانات طلاب حقيقية في المشروع.
- لا يملك `anon` صلاحيات على الجدولين.
- يملك `authenticated` عمليات القراءة والإضافة والتعديل والحذف فقط؛ ولا يملك `TRUNCATE`.
- جميع سياسات القراءة والكتابة مقيّدة بـ `auth.uid()`.

## التشغيل المحلي

من جذر المستودع على فرع `development`:

```bash
python -m http.server 4173
```

ثم افتح:

```text
http://localhost:4173/development/student-registry.html?demo=1
```

احذف `?demo=1` لعرض شاشة الدخول إلى Supabase التجريبي. لا تفتح ملف HTML مباشرة بصيغة `file://` عند اختبار تسجيل الدخول أو استعادة كلمة المرور.

## الاختبارات

```bash
npm run test:students
```

يفحص الاختبار:

- عدم تكرار معرّفات HTML ووجود العناصر التي يستخدمها JavaScript.
- تنظيف بيانات الطالب والقيم الافتراضية.
- قراءة CSV الذي يحتوي فواصل واقتباسات.
- حماية قيم CSV التي قد تُفسَّر كصيغة في برامج الجداول.
- التحقق من نطاق تقييم التقدم التعليمي.

## حدود الأمان والنشر

- لا تعدّل `main` ولا إعداد GitHub Pages من أجل هذه النسخة.
- لا تستخدم بيانات حقيقية في وضع التطوير.
- المفتاح الموجود في JavaScript مفتاح **Publishable** لمشروع التطوير، وليس Secret أو Service Role.
- لا تُدمج الملفات في التطبيق المنشور قبل تنفيذ اختبارات المرحلة الثانية واعتمادها.
